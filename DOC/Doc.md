# Note et procédure réalisée

## Vagrant file

J'ai commencé par créer un fichier Vagrantfile pour configurer une machine virtuelle. Ce fichier contient les paramètres nécessaires pour définir l'environnement de développement, y compris le système d'exploitation, la mémoire allouée, les disques virtuels et les configurations réseau. J'ai choisi d'utiliser Ubuntu comme système d'exploitation pour sa compatibilité avec wazuh (documentation officielle de wazuh).
